# Digital Wallet Management System

A C++ based Digital Wallet Management System supporting regular and premium users.

## Features


- Add money
- Send money
- Show balance
- Cashback
- Transfer money between users
- Search users
- Show all users

## Concepts Used


- Classes and Objects.
- Inheritance.
- Polymorphism.
- Virtual Functions
- Function Overriding
- Operator Overloading
- Dynamic Memory Allocation
